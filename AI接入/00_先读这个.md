# 接入 Coda 课达：AI 先读这份

老师用自己的 AI（Claude Code、Codex 之类）和课达对话：说一句“周三小明上了，小红请假”，你查课表、列清单，老师说可以，你再写进账本。

## 开始前
1. 课达要开着：老师双击 `Mac 点这里.command`。它只在这台电脑上跑（`127.0.0.1:18765`）。
2. 所有命令在这个文件夹的根目录运行，只用系统自带的 python3：
   ```bash
   python3 AI接入/coda_ai.py hours
   ```
   能看到学生余额就接通了。提示“课达没开”就请老师打开。

## 查（随便查，不用问）
| 命令 | 看什么 |
|---|---|
| `hours` | 所有学生的余额 |
| `hours 小明 [条数]` | 这个学生的余额和流水 |
| `week` | 从昨天起 8 天的课，带请假和已记的标记 |
| `courses 2026-11-05` | 那一周的实际课表、course 编号、这周的调整 |
| `gaps [小明]` | 课表上有、账本没记的节次 |
| `texts [--date 日期] [--student 名字]` | 已写的上课内容 |
| `log [--month 2026-11] [--student 名字]` | 操作日志 |
| `changes 小明` | 课时单的改动记录 |
| `paper 小明` | 老课表（起点） |
| `sheets`、`sheet 编号` | 没入账的签课表、一张的识别结果 |

## 写（三步，不能跳）
1. **列清单**：`python3 AI接入/coda_ai.py propose 清单.json`（文件内容见下；也可以用 `-` 从标准输入读）。程序检查格式和学生名字，返回清单编号和每一条的文字。这一步什么都没写。
2. **给老师看**：把程序返回的那几行原样发给老师，问“记上吗？”。不要说“记好了”。
3. **老师说可以才写**：`python3 AI接入/coda_ai.py confirm 编号`。老师说不对就 `reject 编号`，改好重新列。

老师的同意只算这一份清单。程序不会替你拦下没问过老师的 `confirm`，这条靠你遵守。每次写入都进操作日志，原因写的是“AI 接入：老师确认”，老师可以在课时管理里撤销。

清单格式：
```json
{"summary": "周三的课", "items": [
  {"type": "record", "kind": "lesson", "student": "小明", "date": "2026-11-04", "time": "16:00-16:45", "units": 1},
  {"type": "record", "kind": "leave", "student": "小红", "date": "2026-11-04", "time": "17:00-17:45"},
  {"type": "content", "student": "小明", "date": "2026-11-04", "text": "小明 11月4日 周三 16:00–16:45 上课内容\n1. 《小星星》前奏"},
  {"type": "edit", "action": "edit", "id": "流水编号", "student": "小明", "kind": "leave"},
  {"type": "edit", "action": "package", "id": "流水编号", "student": "小明", "perWeek": 4},
  {"type": "schedule", "date": "2026-11-04", "op": {"type": "cancel", "course": "course-1", "note": "老师休假"}},
  {"type": "package", "student": "小明", "start": "2026-11-01", "end": "2026-12-31", "perWeek": 4, "note": "寒假课包"}
]}
```

## 做不了的事，告诉老师在页面上点
删除或撤销记录、缴费、旷课、补课、手动调整、改起点、改固定课表：到 Mac 的课时管理、课程管理里操作。发给家长只有老师自己点。

## 按要做的事接着读
- 记上课、请假：`01_记上课和请假.md`
- 写上课内容：`02_写上课内容.md`
- 查余额、缺记录、记录不见了：`03_查课时.md`
- 临时调课、课包：`04_调课和课包.md`

## 课表里的颜色
课表用蓝、红两种颜色分老师，名字在设置页。记上课时程序按课表自动标是哪位老师，你不用填。
