# 写上课内容

老师说“小明今天学了某首歌的前奏”时用。

## 格式
第一行：`姓名 M月D日 周X HH:MM–HH:MM 上课内容`，下面一行一条：`1. 内容`

```
小明 11月4日 周三 16:00–16:45 上课内容
1. 《小星星》整首
```

## 规矩
- 只写老师说的，不添评价和建议。没听清的写【待补】，比如【曲名未说，待补】。
- 曲名、人名听写可能错；拿不准就在回话里问，内容里留【待补】。
- 时间取课表。清单 type 用 `content`。
- 新内容会盖掉那天的旧内容：先用 `texts --date 日期 --student 名字` 读出来，合并后再列清单。
- 内容只存进课达。发给家长只有老师自己操作。
